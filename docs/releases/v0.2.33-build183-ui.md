# DSHA v183：自动小窗默认关闭，启动日志独立页面

本次按用户要求调整两处使用体验，不更换 DSH、Ubuntu 或发布证书。

## 使用方式

- 新装或从 v182 及更早版本首次升级后，“离开应用时自动进入小窗”默认关闭。切到桌面或其他应用时不会自动显示聊天小窗；主动开启后的选择保存在本机。
- 如有需要，在“设置 → 运行与显示 → 显示”打开该开关，立即生效，无需停止或重启 DSH。系统的画中画许可仍需允许。
- 首页保留状态和启动、进入、停止等操作，移除大块启动输出。点“启动日志”进入独立页面，查看实时输出、下载日志，或进入原有历史记录与诊断页。上翻阅读旧内容时，新输出不会强制拉到底部。
- 本机访问地址仍在首页“访问地址”中查看；局域网连接入口、安全启动和恢复选项保留。

## 实现范围

`picture_in_picture_auto_enter` 使用独立的默认 false 偏好，不继承旧 `picture_in_picture=true` 或系统许可。两个网页内核共用的 `PictureInPictureActivity` 在 Android 12+ 系统参数、Android 8–11 离开回调以及系统小窗请求三条路径中读取它。修改偏好会立即刷新已保留的网页宿主参数。该显示偏好仅在本机保存，不从旧备份中的历史画中画字段推导自动授权。

`StartupLogActivity` 只读取原有 `StartupDiagnostics` 时间线，不发起启动、停止或维护。沿用原有脱敏记录和下载流程；不再把带访问凭据的当前本机地址追加到日志正文。安装页的嵌套日志继续保留原高度限制，独立启动日志使用剩余可用高度。
